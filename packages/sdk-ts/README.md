# @ubos/sdk

The TypeScript SDK of UBOS, version 0.2, for browsers and Node.js 22 or later (PH-1 step
17c, DEC-078). Apache-2.0. No runtime dependencies: it uses the platform's `fetch`,
`WebSocket` and Web Crypto.

```ts
import { connect, VerMergeConflict } from "@ubos/sdk";

const c = await connect({
  url: "https://ubos.example.com",
  vae: "acme",
  auth: { kind: "password", username: "admin", password: "…" },
});
const item = await c.get("ubos://acme/Customer/acme", { branch: "main" });
console.log(item.version, item.evidence, item.body);

for await (const x of c.query('from Customer where this.name != ""', { pageSize: 50 })) console.log(x.slug);

try {
  await c.invoke("ubos://acme/Customer/acme", "rename", { name: "Acme Inc." });
} catch (e) {
  if (e instanceof VerMergeConflict) console.log(e.details);
}

const sub = await c.subscribe("ubos://acme/Customer/acme", (u) => console.log(u.kind));
const { reference } = await c.files.upload(file, { onProgress: (n, total) => console.log(n, total) });
```

Layers (DSN-SDK-001), each usable without the ones above it:

| Layer | Exports | What it does |
|---|---|---|
| Transport | `Link` | HTTP (`POST /ubtp/v1` with server-sent events for `emit`) and WebSocket (`ubtp.v1`) |
| Session | `Session` | handshake and version negotiation, password sign-in, API keys and bearer tokens, reconnection with back-off and re-authentication, subscriptions resumed from their last cursor |
| Operations | `Client`, `Files` | `get`, `query` (async iterator over snapshot pages), `history`, `timeline`, `diff`, `explain`, `mutate`, `invoke`, `commit` (UUIDv7 idempotency keys reused on retries), `subscribe`, `files.upload` (tus, resumable, SHA-256 checked), `files.download` (signed links, ranges) |
| Typed API | `Typed`, `Query` | what `forge types` generates builds on: typed reads, discriminated unions over a class and its subclasses, query builders compiling to DAT-Query, typed port calls |

Errors are instances of their code's class, generated from the error registry STD-ERR-002
(`src/codes.ts`, `src/registry.ts`; `crates/ubos-sdk/tools/gen_registry.py`): `e.code`,
`e.area`, `e.details`, `e.retryable`, `e.catchable`, `e.status`. Only retryable codes and
transport failures (`TransportError`) are retried, with exponential back-off and full
jitter within the call's deadline. `Decimal` and `Money` are exact strings; a non-integer
number anywhere in a mutation is refused with `LogicFloatToDecimal`. A `TraceContext`
passed in the call options travels as a child span in the envelope.

Read coordinates (STD-ADDR-002): `time` is transaction time (the snapshot at that
instant), `commit` a commit (at most one of the two), `asof` valid time; `diff` compares two
`{branch, cseq}` coordinates. A password client keeps its session token across
reconnections and signs in again only when the node refuses it; a dropped stream with open
subscriptions is reopened by itself and the subscriptions resume from their cursors.

## Typed API

`forge types` (DSN-FRG-102) generates `types.ts` for a project; with a class `Party` and
its subclasses `Customer` and `Supplier`:

```ts
import { Account, Party } from "./generated/types.js";

for await (const p of Party.query().filter("country", "==", "US").orderBy("name").run(c)) {
  if (p.class === "Customer") console.log(p.body.credit_limit);   // narrowed to Customer
  else if (p.class === "Supplier") console.log(p.body.iban);
}
await Account.ports.rename(c, "ubos://acme/Account/a-1", { name: "Operating" });
```

A browser application on another origin than the node needs that origin in the node's
`server.cors_origins`. Over WebSocket the tenant travels as the `tenant` query parameter.

## Development

```sh
npm ci
npm run check        # tsc --strict, eslint, build, bundle size (DSN-SDK-017: < 60 KB gzipped)
npm run examples     # the tour for Node.js and the browser
node build/examples/tour.js URL VAE USER PASSWORD ws [--restart]
node examples/browser-check.mjs URL VAE USER PASSWORD http [--restart]   # headless Chromium
```

The SDK suites (SUITE-SDK-PROTO, -NET, -TYPES) run this package's runner `suite/suite.ts`
from `verify/sdk/sdk_suite.py`; `suite/generated/types.ts` is generated by `forge types
verify/sdk/fixture --out packages/sdk-ts/suite/generated --sdk ../../src/index.js`.

The tour needs a VAE with the classes `Customer` (`name`, `email`, `credit_limit` money) and
`Document` (`title`, `passport` blob).
