# PH-2 执行计划（DEC-085）

PH-2 交付第一个完整产品：高可用 Server、专业 Web 工作台、精简 Studio 与 Bridge，以及第一个业务包——Basic Finance Buk（美国标准总账、应收、应付、银行、固定资产、多币种与结账，DEC-022）。目标 G2：财务包运行时内核中没有任何财务专用代码（EXIT-2-04）。和 PH-1 一样，由业主和 AI 会话执行，每一步按各自的 DEC 拆成若干 PR，由业主合并。`main` 是 PH-2 的开发线；PH-1 冻结在 `release/ph1`（DEC-085）。先标准后代码（AR-033）：需要标准中没有的内核能力时，先出 BPA 1.0 候选版的条款与向量。

步骤和退出标准的英文原文见 UBS-PH-2 §11 与 §9。
