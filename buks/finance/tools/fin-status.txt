# A requirement whose ID a test name carries is "tested" and needs no line here. Every other
# requirement has one line:  ID | status | evidence | note
#   covered   implemented in the Buk and exercised by the tests whose names contain each of the
#             ';'-separated evidence fragments (checked)
#   platform  met by the kernel or the platform, verified there: the evidence names the reference
#   assigned  built in a later step: the evidence names the step (PH-2 step N, or PH-3)
#   gap       to be built in the Buk (none since step 10g-3)
# Must requirements may not stay "gap" when step 10 closes (fin_coverage.py --closing).
